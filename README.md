# Finanças Pessoais

Aplicação web simples (HTML/CSS/JS, sem build) para gerir receitas, despesas e orçamento mensal.

- Categorias de despesa e receita com ícones de linha
- Gráficos (Chart.js): despesas por categoria e tendência de 6 meses
- Orçamento mensal com barra de progresso
- Tema automático / claro / escuro
- Dados guardados no `localStorage` do navegador

Abrir `index.html` no navegador.
